# Reproducibility statement

The primary experiment has deterministic decisions and aggregate endpoints under local-CPU evaluation. It uses four fixed trace instantiations (`20260712`--`20260715`), twelve frozen single-fault operators, and zero recorded retries. Clean traces and corrupted copies are created in a temporary directory; only case records, execution metadata, and the append-only ledger are retained. The paper's headline counts are independently recomputed from that ledger by `scripts/research/build_trace_audit_analysis.py`. Amendment A-001 corrects macro-recall summary metadata without rerunning or altering any case. Amendment A-002 excludes the under-specified `wall_seconds` secondary endpoint from interpretation: each row's `elapsed_seconds` is a host-dependent diagnostic covering both checks, so reproduced decisions and summaries need not yield byte-identical timing-bearing ledger rows.

The real-MACE case study is reused rather than rerun. Its environment, exact Git commit, dataset/split/checkpoint identities, NVIDIA L4 attestation, `mace-torch`/torch dependency versions, operation receipts, aggregate evaluations, trace grade, artifact manifest, and cleanup confirmation are bound by hashes in the private evidence map. The anonymized submission refers to this bundle as `remote-trace-A`. Its status is `infrastructure_only`; no protected partition or acquisition label is disclosed.

Reproduction commands are listed in `appendix.tex` and write to a new output directory so they cannot overwrite frozen evidence. No network, remote compute, W&B sync, API key, or `api.env` access is required for the primary experiment.
